# RHWP 한글 기능 로드맵

이 문서는 RHWP 데스크톱 앱을 한컴오피스 한글에 더 가깝게 확장하기 위한 우선순위 문서입니다.

## Phase A: 파일/출력/경고

- 글꼴 경고를 실제 대체 상황만 보여주도록 정리
- 파일 메뉴에 `다른 이름으로 저장` 추가
- 파일 메뉴에 `다른 확장자로 저장` 추가
- `HWP`, `HWPX`, `PDF`, `DOCX`, `JPG` 저장 경로 제공
- 보호보기 문서에서도 `PDF`, `DOCX`, `JPG` 내보내기 허용

## Phase B: 주석/참조/문서 메타

- 하이퍼링크 편집
- 주석/미주 편집
- 필드 입력 편집
- 캡션 편집
- 파일 정보/문서 메타 필드 노출

## Phase C: 표 편집 완성

- 행/열 추가 삭제
- 셀 병합/분할
- 셀 테두리/배경 편집
- 블록 계산식과 표시 형식

## Phase D: 서식/스타일/대화상자

- 글자 모양 대화상자
- 문단 모양 대화상자
- 스타일 관리
- 글머리표/문단 번호 모양
- 보기 설정과 도구 상자 확장

## Phase E: 고급 개체와 한글 특화 기능

- 수식 편집 고도화
- 그룹/개체 배치
- 머리말/꼬리말 고급 편집
- 검토/개정 흔적
- 양식 개체
- 마스터 페이지 계열

## 우선순위 기준

- `rhwp-studio/index.html`에 남아 있는 `disabled` 메뉴
- 현재 커맨드 미구현 목록
- 보호보기와 저장 호환성에 직접 영향을 주는 기능
