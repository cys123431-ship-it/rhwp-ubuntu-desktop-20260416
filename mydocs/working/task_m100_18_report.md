### B. UI/UX 전수 검토 및 핫픽스
1. **서식 도구 모음(style-bar) 너비 확장**: `style-bar.css` 내 스타일 이름, 글꼴, 줄간격 콤보박스의 안전 가로 폭을 확보하여 "바탕글", "대표", "함초롬바탕", "160%" 등의 텍스트 짤림을 영구 해소했습니다.
2. **다이얼로그 스크롤 제공**: `dialogs.css`에 `.dialog-body { max-height: 65vh; overflow-y: auto; }`를 부여하여 화면 크기 축소 시 혹은 "제품 정보" 등 내용이 아주 긴 다이얼로그에서 스크롤을 활성화하고 닫기 버튼이 화면을 벗어나는 오류를 수정했습니다.
3. **도구 상자(icon-toolbar) 가로 스크롤 및 드롭다운 가시성 유지**: `toolbar.css`에 가로 오버플로우 스크롤을 도입하여 창 폭 축소 시 버튼 유실을 막고, 모던 CSS `:has()` 가상 클래스를 활용해 드롭다운 개방 시 `overflow: visible`로 동적 반전시켜 서브메뉴 잘림 버그를 완치했습니다.
