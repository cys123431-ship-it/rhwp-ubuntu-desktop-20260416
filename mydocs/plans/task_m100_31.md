## 현황 분석

### 사용자 요구 및 감사 결과

1. **가독성 저하**: 에디터 화면에 렌더링된 본문 텍스트가 번지고 흐릿하여 가독성이 현저히 떨어진다는 불만이 접수되었습니다. 사용자는 "글씨가 검은색인데 흰색이랑 섞여서 나오는 것 같다"고 호소하고 있습니다.
   - **소수점 픽셀 어긋남 (Subpixel Misalignment)**: 캔버스를 화면 중앙에 배치하기 위해 사용하고 있는 `left: 50%; transform: translateX(-50%)` CSS 규칙과 JS 상의 레이아웃 배치가, 캔버스 너비가 홀수 픽셀이거나 1.25배 등 고해상도(HiDPI) 스케일링 환경 하에서 소수점 픽셀 배치를 유발합니다. 이로 인해 브라우저의 빌리니어 필터링(Bilinear Filtering)이 적용되어 텍스트 외곽선이 뿌옇게 번집니다.
   - **서브픽셀 폰트 스무딩 노이즈**: Linux WebKitGTK(Tauri) 환경에서 폰트의 LCD 서브픽셀 힌팅이 발생할 때 주황/파란색 컬러 프린징 잔상이 흐릿하게 뭉개지며 눈을 피로하게 만듭니다.
2. **데스크톱 버전 표시 정합성 어긋남**: 사용자가 데스크톱 빌드를 완성하고 최신 `0.1.12` deb 패키지를 완벽히 설치했음에도 불구하고, 제품 정보 대화상자에는 여전히 구버전인 `Desktop 0.1.11` 로 표시되고 있습니다.
   - **원인**: `rhwp-studio/src/ui/about-dialog.ts` 소스 내에 `const DESKTOP_RELEASE_VERSION = '0.1.11';` 로 버전 상수가 하드코딩되어 있습니다. 실제 패키지(`rhwp-desktop/package.json` 및 `tauri.conf.json`)의 빌드 버전은 `0.1.12` 로 올바르게 빌드되었으나, UI 단의 버전 텍스트가 갱신되지 않고 누락되었습니다.

## 수행 범위

### 포함

1. **JS/TS 레벨의 정수 픽셀 배치 적용** (`rhwp-studio/src/view/canvas-view.ts`):
   - 캔버스 중앙 정렬이 필요한 영역에서 스크롤 컨테이너의 너비와 캔버스의 CSS 너비를 기반으로 `Math.floor()`를 사용해 완벽히 짝수/정수로 딱 떨어지는 left 좌표값을 동적으로 계산 및 주입.
   - `transform = 'none'` 처리로 브라우저 하드웨어 가속에 의한 미세 스케일링 번짐 차단.
2. **CSS 레벨의 폰트 가독성 극대화 최적화** (`rhwp-studio/src/styles/editor.css`):
   - `#scroll-content canvas`에 기재된 `left: 50%` 및 `transform` 제거 (TS/JS에서 완전히 절대 좌표 정수로 정밀 제어).
   - 리눅스 WebKit 환경 하에서 폰트 가독성을 보정하는 `-webkit-font-smoothing: antialiased`, `-moz-osx-font-smoothing: grayscale` 주입.
   - 이미지 및 대비 경계를 명확히 해주는 `image-rendering: -webkit-optimize-contrast` 및 `image-rendering: crisp-edges` 설정 추가.
3. **UI 제품 정보 버전 정합성 보완** (`rhwp-studio/src/ui/about-dialog.ts`):
   - 하드코딩된 `DESKTOP_RELEASE_VERSION`을 현재 실제 빌드 및 배포 패키지 버전에 부합하는 `'0.1.12'` 로 업데이트 및 갱신.
   - '이번 설치본 변경사항' 영역의 표시 문자열도 `v0.1.12` 로 싱크.

### 제외

- `src/renderer/web_canvas.rs` 내 Rust 렌더러의 문자폭, 글꼴 캐싱, 드로잉 엔진 핵심 알고리즘의 대규모 수정.
- 장평, 자간 등 텍스트 메트릭스 레이아웃 엔진의 재계산 로직 수정 (물리 픽셀 정렬에 국한하여 보완).

## 검증 기준

- `npx tsc --noEmit`을 통한 TS 컴파일 통과 확인.
- 브라우저 요소 검사 시 각 페이지를 나타내는 `canvas`의 `left` 스타일 값이 항상 소수점 없는 정수 픽셀(예: `123px`, `45px`)로 설정되어 있는지 확인.
- 100%, 125%, 150% 등 다양한 화면 배율 및 줌(Zoom) 배율에서 텍스트의 미세한 주황/파랑 색상 번짐이 완전히 소멸하고 선명한 그레이스케일 안티앨리어싱으로 미려하게 렌더링되는지 시각적 확인.
- 제품 정보 대화상자를 열었을 때 `Desktop 0.1.12` 및 `이번 설치본 변경사항 v0.1.12`로 정확하게 갱신 표시되는지 검증.
