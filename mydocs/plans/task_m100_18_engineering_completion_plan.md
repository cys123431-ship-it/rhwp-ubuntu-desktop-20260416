# M100 #18 소프트웨어 공학 기반 완성 계획

## 목표
- RHWP를 한컴 한글의 안전한 오픈소스 호환 구현으로 완성한다.
- UI 복제보다 HWP/HWPX 열기, 렌더링, 편집, 저장, 재열기, 3플랫폼 설치 품질을 우선한다.
- 웹, Windows, Ubuntu가 같은 기능 기준과 같은 릴리즈 게이트를 통과해야 완료로 본다.

## 참고한 최신/주류 기법
- ISO/IEC/IEEE 29148 요구사항 공학: 요구사항, 검증 항목, 산출물을 추적 가능한 정보 항목으로 관리한다.
- DORA 2024/2025 흐름: 배포 빈도, 변경 리드타임, 실패 복구 시간, 변경 실패율, 배포 재작업률을 품질 운영 지표로 둔다.
- 테스트 피라미드: Rust 단위 테스트와 파서/저장 계약 테스트를 넓게 깔고, E2E와 시각 회귀는 핵심 사용자 흐름에 집중한다.
- Playwright 시각 회귀: 한컴 유사 렌더링 품질은 스크린샷/좌표/허용오차 기반 골든 테스트로 고정한다.
- OWASP ASVS 5.0: 웹/데스크톱의 파일 입력, 권한, 저장, 보안 표시, 민감 데이터 처리를 검증 요구사항으로 관리한다.
- SRE 오류 예산: 데이터 손상, 저장/재열기 실패, 입력 오동작, 크래시는 오류 예산 0으로 두고 기능 추가보다 먼저 막는다.

## 운영 원칙
- 기능 상태는 `implemented | partial | stub | unsupported | missing | bug`로만 표기한다.
- “버튼이 눌림”은 완료가 아니다. 열기, 편집, 저장, 재열기, 렌더링, Undo/Redo, 3플랫폼 확인까지 지나야 `implemented`다.
- 한컴과 다른 동작이 발견되면 기능 추가보다 회귀 방지 테스트를 먼저 만든다.
- 릴리즈 후보는 Windows 설치본, Ubuntu 패키지, 웹 정적 빌드가 같은 체크리스트를 통과해야 한다.

## 단계 계획
1. 안정성 기준선 고정
   - 현재 `Shift+=` 입력 충돌 같은 기본 입력 문제를 P0/P1로 닫는다.
   - 단축키, 메뉴, 도구 상자, hwpctl Action, WASM API 연결 누락을 자동 검사한다.
   - 웹 빌드, Rust 테스트, Windows 설치본 스모크를 매번 같은 명령으로 재현한다.
2. 요구사항 추적표 완성
   - `파일/편집/보기/입력/서식/쪽/표/검토/보안/플랫폼` 축으로 한컴 기능을 쪼갠다.
   - 각 항목에 한컴 기준, RHWP 커맨드, hwpctl Action, 테스트, 플랫폼 결과, 상태값을 연결한다.
3. 호환성 코퍼스 강화
   - 원본 HWP/HWPX, RHWP 저장본, 재파싱본, 페이지 수, 좌표 허용오차, 보호 보기 상태를 한 묶음으로 기록한다.
   - 문단, 표, 그림, 도형, 머리말/꼬리말, 각주, 다단, 조판 부호가 들어간 샘플을 우선한다.
4. 편집 기능 완성
   - 블록 선택, 글자/문단 모양, 표 셀 블록, 그림/도형, 하이퍼링크, 주석/각주/미주, 쪽 번호, 구역/다단을 순서대로 닫는다.
   - 각 기능은 Undo/Redo와 저장 후 재열기를 완료 조건으로 둔다.
5. 렌더링/저장 회귀 게이트
   - `dump`, `dump-pages`, `ir-diff`, SVG/PDF/JPG 내보내기, Playwright 스크린샷 비교를 릴리즈 게이트로 묶는다.
   - 픽셀 차이는 허용오차를 명시하고, 페이지 수 불일치는 주요 샘플에서 0건을 목표로 둔다.
6. 3플랫폼 출시 안정화
   - Windows current-user/NSIS, Ubuntu `.deb`, 웹 정적 배포를 같은 버전 번호와 릴리즈 노트로 묶는다.
   - 파일 연결, 더블 클릭 열기, 드래그 앤 드롭 열기, 자동 복구, 인쇄/내보내기, 큰 문서 성능을 확인한다.

## 완료 기준
- P0 0개: 데이터 손상, 저장/재열기 실패, 입력/단축키 오동작, 크래시가 없어야 한다.
- P1 0개: 기본 메뉴, 서식, 표, 쪽, 찾기, 파일 연결, 설치 흐름의 주요 불일치가 없어야 한다.
- 기능 추적률 100%, 신규 숨은 stub 0개.
- 주요 호환성 샘플 페이지 수 불일치 0건.
- Windows, Ubuntu, Web 릴리즈 산출물이 같은 체크리스트를 통과한다.

## 바로 다음 실행 항목
- `Shift+=` 입력 충돌 수정본을 `0.1.9`로 빌드, 설치, 검증한다.
- 단축키/기능 추적표에 “일반 문자 입력과 보기 단축키 충돌” 항목을 `bug -> implemented`로 반영한다.
- 이후 한컴 기본 입력/단축키 회귀 테스트를 E2E로 확장한다.
