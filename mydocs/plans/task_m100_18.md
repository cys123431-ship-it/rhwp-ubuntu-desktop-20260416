# M100 #18 수행 계획서: 한컴 기능/단축키 전수 검토

## 작업 개요

- 작업일: 2026-04-28
- 이슈: <https://github.com/cys123431-ship-it/rhwp-ubuntu-desktop-20260416/issues/18>
- 브랜치: `local/task18`
- 목표: RHWP가 한컴 한글 기준으로 기능, 단축키, 블록 편집, 저장/재열기, 3플랫폼 동작을 어디까지 만족하는지 추적 가능한 기준선을 만든다.

## 수행 범위

1. 한컴 공식 도움말과 제품 설명을 기준으로 기능/단축키 기준표를 만든다.
2. RHWP의 `shortcut-map.ts`, command registry, hwpctl Action, E2E 커버리지를 연결한다.
3. 블록 선택 후 글자 크기 증가/감소를 P0 회귀 항목으로 고정한다.
4. `implemented | partial | stub | unsupported | missing | bug` 상태값으로 기능 완성도를 분류한다.
5. 웹/Windows/Ubuntu 게이트를 한 표에서 추적한다.

## 완료 기준

- 한컴 글자 크기 단축키 `Alt+Shift+E`, `Alt+Shift+R`와 기존 `Ctrl+]`, `Ctrl+[`가 모두 RHWP에서 같은 동작을 한다.
- 단축키 맵의 커맨드 연결이 정적 검사로 검증된다.
- 기능/단축키/플랫폼 게이트의 남은 결함이 P0/P1/P2로 분류된다.
