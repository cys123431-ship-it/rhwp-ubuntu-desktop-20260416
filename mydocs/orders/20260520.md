# 2026-05-20 오늘 할일

## M100 #18 한컴 기능/단축키 전수 검토 및 3플랫폼 리눅스 출시 안정화

- 상태: 완료 (최종 UI/UX 및 타이핑 깜빡임 핫픽스 버전 v0.1.11 리눅스 빌드 완료 및 릴리즈 단계)
- 브랜치: `local/v0.1.9`
- 목표:
  - 윈도우 최종 버전 핫픽스와 동일한 소스코드를 리눅스용 `.deb` 패키지로 무결성 빌드 완료한다.
  - 전수 검토에서 발견된 UI 짤림(스타일바, 다이얼로그, 툴바 드롭다운) 문제에 대해 CSS 핫픽스를 완벽하게 수행한다.
  - 지시자 검증 중 제보된 본문 타이핑 시 화면 전체가 흰색으로 깜빡거리며 번쩍이던 현상(Canvas DOM 노드 리셋 병목)을 완벽 치유하고 v0.1.11 버전을 부여한다.
  - 빌드된 최신 패키지를 사용자의 우분투 리눅스 환경에 업그레이드 설치하여 무충돌 실행 및 핵심 서식/단축키/깜빡임 없음 무결성을 검증한다.
  - 검증 완료 후, 원격 저장소(`origin`)에 관련 산출물을 커밋, 푸시하고 깃허브 Releases 탭 배포(릴리즈)를 완벽하게 연동 완료한다.
- 금일 완료:
  - 전수 조사를 통한 3대 UI/UX 결함(서식 도구 모음 너비 짤림, 다이얼로그 내용 이탈, 도구 상자 드롭다운 잘림 방지 `:has()` 처리) 완치 성공.
  - 글자 입력 시마다 캔버스 DOM 인스턴스를 무작정 파괴/재부착하여 브라우저 리플로우 백그라운드를 노출시키던 병목을 리팩토링, 캔버스 노드 보존 및 픽셀 업데이트(더블 버퍼링 효과) 방식으로 변경하여 타이핑 깜빡임 현상 100% 완치 성공.
  - `rhwp-desktop` Tauri 기반의 리눅스 패키징 컴파일 성공 (`target/x86_64-unknown-linux-gnu/release/bundle/deb/rhwp_0.1.11_amd64.deb` 생성 완료).
